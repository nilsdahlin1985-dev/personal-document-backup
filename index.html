Personal utility

Personal Document Backup

A private-use backup configuration that uses rclone on the account holder's computer to export selected Google Docs into local document files.

Purpose and operation

The tool is intended to run on a schedule, download editable documents and PDF reading copies, and retain earlier local copies when documents change. Configuration and scheduling are managed on the account holder's computer.

Google account access

The desktop tool requests read-only Google Drive access so that it can list files and download or export selected documents. The permission covers viewing and downloading files accessible to the authorized account; the backup selection is controlled separately in rclone's configuration.

Google sign-in is handled by Google. Credentials and authorization tokens are stored locally by the account holder and rclone.

About this website

This website provides information about the personal backup configuration. It has no sign-in form, upload feature, or connection to the account holder's documents. The document transfers take place between Google and the locally running tool.

Read the privacy policy for details about access, storage, retention, and revocation.

Use and contact

This configuration is for the account holder's own use. It is provided as a personal utility without a service guarantee; the operator is responsible for configuring and checking their backups. Questions about the configuration should be directed to the account holder who operates it.
